Plan the implementation for: $ARGUMENTS

Do not write code yet. Produce:

- **Approach** — high-level strategy in 2–4 sentences
- **Critical files** — what we'll touch, with paths
- **Step-by-step plan** — ordered, granular enough to execute against
- **Architectural tradeoffs** — anything notable about the design choices
- **Open questions** — what you'd want answered before starting

If the task is genuinely small/obvious, say so and skip sections that don't apply. Don't manufacture complexity to fill the template.
